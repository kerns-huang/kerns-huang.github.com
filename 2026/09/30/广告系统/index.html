价格指标计算

本文整理程序化广告里 eCPM、CPM、CPC 的计算口径。仓库当前出价代码只读取计划上的 bid_cpm / max_bid_cpm，没有按计费方式换算；下面的公式来自公开的 DSP 出价与广告报表定义，供后续实现和报表对齐。

金额在公式里用同一币种即可。落到本仓库时，金额字段单位是分，点击率按万分比存储（50 表示 0.5%）。

1. 三个指标分别算什么

指标 全称 回答的问题 计算时机
CPM Cost Per Mille，千次展示成本 每一千次曝光花多少钱 计划出价，或按展示结算后的报表
CPC Cost Per Click，单次点击成本 每一次点击花多少钱 计划出价，或按点击结算后的报表
eCPM effective / expected Cost Per Mille，有效（或预估）千次展示成本 不管原来按 CPM 还是 CPC 卖，折成每一千次曝光值多少钱 竞价前用预估点击率算出价；投放后用真实消耗和曝光回算

ADX 的竞价单位是 CPM。CPC 计划不能直接拿「单次点击价」去和别人的「千次曝光价」比，要先折成 eCPM，再参与排序和回价。

2. 报表口径（投放之后）

报表用真实消耗、曝光、点击，不依赖预估模型。Google Ad Manager / AdMob 的定义是：收入（或消耗）除以曝光再乘 1000 得到 eCPM，CPC 等于收入（或消耗）除以点击。

记：

  • Cost：该维度下的广告消耗
  • Impressions：曝光次数
  • Clicks：点击次数

几点对齐方式：

  • 只按 CPM 结算时，报表 CPM 与 eCPM 相同，都是千次曝光的实际花费。
  • 只按 CPC 结算时，消耗来自点击：Cost = Clicks × 成交 CPC。此时没有单独的「展示单价」，用来和 CPM 计划对比的是 eCPM。
  • 把上面的 CPC、CTR 代回去，CPC 计划的事后 eCPM 可以写成：
  • 曝光为 0 时不算 CPM / eCPM；点击为 0 时不算 CPC。

例：消耗 90 元，曝光 10,000，点击 90。

  • CTR = 90 / 10000 = 0.9%
  • CPM 或 eCPM = 90 / 10000 × 1000 = 9 元
  • CPC = 90 / 90 = 1 元
  • 用 CPC 回算：1 × 0.009 × 1000 = 9 元，与 eCPM 一致

3. 竞价口径（请求进来时）

竞价时还没有这次曝光的真实点击，用预估点击率 pCTR（predicted CTR，0～1 的小数）代替 CTR。DSP 内部把不同计费方式都折成 eCPM，按 eCPM 从高到低选一条，再把这个价格以 CPM 单位返回给 ADX。

内部胜出的 eCPM 还要落在广告位底价和计划上限之间，才作为 bid.price（分/CPM）返回：

底价或上限不满足则这条计划不出价。多条计划同时可投时，按 eCPM 取最高的一条（本仓库当前实现按 priority、weight 排序，尚未按 eCPM 排序）。

更完整的在线调价会在基础 eCPM 上再乘预算节奏、一价拍卖的压价、以及目标成本纠偏：

  • Pacing：预算花得过快则小于 1，花得过慢则大于 1。
  • Shading：一价拍卖里通常取 0.7～0.95，避免按预估价值全额出价。
  • Correction：实际 CPC（或 CPM）高于目标时压价，低于目标时放价。

这三项目前都没有进 dl-rtb，实现第一版时可以先只做第 3.1、3.2 节的基础 eCPM。

5. 对照例

场景 输入 计算 结果
CPM 出价 bid_cpm = 300 分 eCPM = CPM 出价 300 分（3 元/千次）
CPC 出价 CPC = 200 分，pCTR = 50（0.5%） 200 × 50 / 10 出价 1000 分（10 元/千次）
CPC 报表 消耗 2000 分，曝光 10000，点击 20 CPC = 2000/20；eCPM = 2000/10000×1000 CPC = 100 分；eCPM = 200 分
同一 CPC 不同点击率 CPC = 100 分；pCTR 1% 与 0.2% 100×0.01×1000 与 100×0.002×1000 eCPM 分别为 1000 分、200 分

参考

  • 互联网广告：CPM 和 eCPM 有什么不同（人人都是产品经理）：CPM 时 eCPM = CPM；CPC 时 eCPM = CTR × CPC × 1000。
  • Price Model in DSP System（LeadsWORK）：固定 CPM、TCPM、TCPC 的线性出价；TCPC 的基准 CPM = TCPC × AVG_CTR × 1000。
  • DSP Bidding Strategies：eCPM = 1000 × p(click) × Target CPC；最终出价再乘 Pacing、Shading、Correction。
  • Google AdMob：eCPM：eCPM = (Total Earnings / Impressions) × 1000。
  • Google Ad Manager report metrics：eCPM = (Revenue / impressions) × 1000；CPC = Estimated revenue / Clicks。
